Data Deletion Instructions

This application is used to automate publishing of content to a Facebook Page managed by the user.

How to request data deletion

If you want to request deletion of data associated with this application, please contact the application owner through the GitHub repository where this application is maintained.

Include your Facebook Page name and explain your deletion request. Do not send your password or access token.

The application owner will review your request and delete any applicable data stored by the application, subject to applicable legal requirements.

This application does not claim to delete data held by Meta or Facebook. To manage data held by Meta, use Facebook's own settings and help resources.
