Privacy Policy

Last updated: October 17, 2026

This application automates the publishing of AI-generated images, videos, captions, and other content to a Facebook Page managed by the application owner.

Information and Access

The application may use Facebook Page information and permissions authorized by the Page administrator to publish content. It uses an access token to communicate with Meta's APIs.

How Information Is Used

Information and permissions are used only to operate the application's publishing features and troubleshoot technical issues.

Storage and Security

Access credentials are intended to be stored securely as GitHub Actions secrets and not included in public source code. Workflow logs may contain limited technical information required to diagnose failures.

Sharing

The application does not sell personal information. Data may be processed by Meta and GitHub as necessary to provide their respective services, subject to their privacy policies.

Data Deletion

To request deletion of information held by the application, contact the application owner through the GitHub repository where the application is maintained. Do not include passwords or access tokens in your request.

To manage information held by Meta, use Facebook's account settings and privacy tools.

Changes to This Policy

This policy may be updated when the application's features or data practices change.
